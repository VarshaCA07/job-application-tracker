# Job Application Tracker

A tool I built to track my own internship applications — company, role, status, and notes, all in one place.

## Features
- Add, update, and delete job applications
- Track status (Applied, Interview, Offer, Rejected)
- Filter applications by status
- Data persists locally using localStorage

## Tech Stack
React, TypeScript, Tailwind CSS, Vite

## Why I built this
I was manually tracking internship applications in a notes app and kept losing track of statuses. Built this to solve that problem for myself while practicing React fundamentals — state management, component composition, and data persistence.
